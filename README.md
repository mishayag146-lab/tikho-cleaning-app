# Тихо — запись на химчистку мебели

Мобильный сайт/PWA для мастера по выездной химчистке мебели. Клиент выбирает мебель, видит предварительную стоимость, прикладывает фото и оставляет заявку. Владелец получает заявку в кабинете, согласует окончательную цену и время, меняет тарифы и оформление.

## Возможности

- Каталог мебели и предварительный расчёт стоимости.
- Заявка с контактами, адресом, пожеланиями и до трёх фотографий.
- Клиентская ссылка для отслеживания статуса.
- Кабинет владельца для обработки заявок и настройки тарифов.
- PWA для установки на главный экран телефона.

## Технологии

Next.js 16, React 19, TypeScript, Tailwind CSS, Vinext, Cloudflare Worker, D1 и R2.

## Локальный запуск

Нужен Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

Сайт обычно открывается на http://127.0.0.1:5173/. Для работы с заявками нужны локальные привязки D1/R2 и миграция `drizzle/0000_wise_micromacro.sql`. Доступные проверки: `npm run build` и `npm run lint`.

## Структура

- `app/shop.tsx` — форма клиента и страница заказа.
- `app/admin.tsx` — кабинет владельца.
- `app/api/[[...path]]/route.ts` — серверный API.
- `lib/domain.ts` — каталог, настройки и расчёт цены.
- `db/schema.ts` — схема базы данных.
- `.openai/hosting.json` — привязки D1/R2 для Sites.

## Перед использованием с реальными клиентами

Это демонстрационный проект. Сейчас ссылка заказа открывает контакты и фотографии тому, у кого есть токен. Нужны срок действия и отзыв ссылок, ограничение запросов, а также политика хранения и удаления персональных данных. Авторизация владельца использует доверенный заголовок хостинга Sites; при переносе на VPS требуется собственная серверная авторизация.

Код основан на идее из [ролика о приложении для химчистки мебели](https://youtu.be/EldVrt2-1Pk?t=3). Публикация исходников на GitHub сама по себе не запускает сайт.
